// what it does

Everything your clipboard forgets, clipd keeps.

Fast recall, private storage, Linux Wayland support, and backups that run on schedule.

Text & image history

Every copy is saved with thumbnails — including GNOME Wayland image and screenshot capture on Linux.

Instant search & filters

Live search as you type, with All / Text / Images / Pinned filters.

Win+J

Global hotkey

Summons the popup instantly, with smart cursor placement and window position memory between launches.

Pin what matters

Pin snippets you reuse so they never get evicted from history, no matter how much you copy.

Private Vault

PIN- or password-protected encrypted storage, with optional encrypted vault entries in backups.

Downloads & ZIP exports

clipd · v2.0.1 (Win) · v1.6.0 (Linux)

// latest release

What is new in clipd

A quick first-run tour of the newest Windows and Linux builds. The tab is selected automatically from your device.

GNOME Wayland ready

Daily backups, smart window memory, and live stats

Linux v1.6.0 adds scheduled backups, fixes popup placement with persistent window memory, and polishes the app across search, keyboard navigation, titlebar actions, and vault forms.

Install

sudo apt install ./clipd_1.6.0_amd64.deb
clipd restart

Upgrading from before v1.5.0? Log out and back in once so GNOME Shell loads the image-capable watcher extension.

🗄️ Daily backup system

  • Scheduled daily ZIP backups with a configurable time and folder.
  • Backs up the last 24 hours, with optional pinned items from any age.
  • Vault entries stay encrypted in vault/entries.json.
  • Missed backup slots run at next clipd start, with desktop notifications.

🪟 Remember window position

  • Popup reopens exactly where you last closed it, even after restarts.
  • Uses raw X11 coordinates through xdotool to avoid GNOME scaling quirks.
  • Settings include a toggle to return to centered behavior.

📊 Live stats and smoother navigation

  • Filter chips show the total database count.
  • Optional RAM usage display for clipd and WebKit processes.
  • Arrow keys, PageUp/PageDown, Home/End, and Enter work from anywhere.

✨ Polish and fixes

  • Search clear button, tinted titlebar buttons, and restored vault input icons.
  • Minimize works in windowed mode.
  • The popup no longer hides while a native save dialog is open.

Standalone GNOME extension install

The .deb already installs these. For manual setups, install the helper to /opt/clipd-watcher/main.py, install the extension ZIP, enable clipd-watcher@syedamirali, then log out and back in.

Native Windows clipboard history, no installer required

Clipd 2.0 for Windows is built from the ground up with native clipboard monitoring, Win32 image handling, a frameless always-on-top popup, and a tray workflow that feels at home on Windows.

Download

⌨️ Hotkey and popup

  • Default global hotkey Win + J, customizable in settings.
  • Popup opens at your cursor, toggles closed on the next hotkey press, and can auto-close on focus loss.
  • Auto-paste sends Ctrl + V to the previously focused window.

📋 History and vault

  • Text and images are captured automatically with fast search.
  • Private vault keeps sensitive items separate.
  • Pinned items can stay only in the Pinned tab when you prefer a cleaner All tab.

💾 Files and export

  • Save text or image items to a configurable folder.
  • Files are sorted into text/ and images/ subfolders.
  • Export all history to a ZIP archive in one click.

🔔 Tray, taskbar, and autostart

  • Tray icon with Show, Toggle, and Quit actions.
  • Named-pipe IPC supports clipd stop, clipd quit, and clipd toggle.
  • Taskbar mode, autostart on login, and embedded Windows version metadata.
